۱. ساخت مپ و دریافت کد ۴ رقمی

قبل از شروع، یک کد ۴ رقمی مخصوص شما ساخته می‌شود. کد را به دوستتان بدهید تا وارد مپ شما شود.

----
برای ساخت کد روی دکمه زیر بزنید

۲. ورود با کد دعوت دوست

کد ۴ رقمی که برای دوستتان نمایان شده را در کادر زیر وارد کنید و سرچ بزنید تا مستقیم وارد مپ او شوید.

💡 نکته: این سیستم هم روی اینترنت (از طریق GitHub Pages و WebRTC) بین دو سیستم مختلف کار می‌کند و هم اگر بازی را در دو تب مرورگر روی یک سیستم باز کنید فوراً متصل می‌شود!

🌐 راهنمای آنلاین کردن بازی با GitHub Pages

  1. کدهای این بازی را با نام index.html ذخیره کنید.
  2. وارد سایت GitHub.com شوید و یک Repository (مخزن) جدید و Public بسازید.
  3. فایل index.html را داخل مخزن خود آپلود (Upload) کنید و روی Commit بزنید.
  4. وارد بخش Settings مخزن شوید، از منوی سمت چپ گزینه Pages را بزنید.
  5. در قسمت Branch گزینه main را انتخاب کرده و Save را بزنید.
  6. بعد از ۱ دقیقه لینک سایت شما آماده است! لینک را برای دوستتان بفرستید، یک نفر در بخش آنلاین کد ۴ رقمی بسازد و نفر دوم همان کد را وارد کند تا با هم داخل یک مپ بازی کنید.
